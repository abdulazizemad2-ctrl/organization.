# المنظمة الدولية للتنمية والابتكار — IODI

موقع تفاعلي لمشروع **International Organization for Development & Innovation**، في ملف واحد (`index.html`) يعمل مباشرة في المتصفح دون خادم.

## الأدوات
1. **محاكي التصويت:** قاعة مرئية للجمعية العامة، وجلسة تصويت حية، وسيناريوهات جاهزة، وفق النصاب والأغلبيات في الميثاق (بسيطة، ثلثين، ثلاثة أرباع).
2. **محاكي تسوية النزاع:** المراحل الأربع (المشاورات، الوساطة، المساعي الحميدة، هيئة التسوية) مع سجل تلقائي ومحضر قابل للطباعة.
3. **شهادة العضوية:** شهادة بالشعار ورقم عضوية وتاريخ هجري وميلادي، قابلة للطباعة والحفظ PDF.

## التشغيل
افتحي `index.html` في أي متصفح. وللنشر: Settings ← Pages ← Deploy from branch ← `main` / root.
